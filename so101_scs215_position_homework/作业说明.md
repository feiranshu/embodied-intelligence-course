# SO-101 机械臂 SCS215 舵机编号、校准与六关节控制

## 1. 作业目标

本项目完成以下功能：

1. 为六只 Feetech SCS215 舵机依次设置 ID 1～6。
2. 记录每个关节的两个机械安全端点，建立校准区间。
3. 输入六个 `0～1` 的归一化数值，将它们转换为舵机原始位置，使六个关节同时平滑运动到目标位置。

代码不依赖 LeRobot，只依赖 Python 和 `pyserial`。这样可以直接使用 SCS215 的寄存器和串口协议，避免将 LeRobot 默认的 STS3215 参数误用到 SCS215。

## 2. 硬件和组装

机械结构按 [Hugging Face 官方 SO-101 组装文档](https://huggingface.co/docs/lerobot/main/en/assemble_so101#step-by-step-assembly-instructions) 安装。六个关节和 ID 的对应关系为：

| ID | 程序名称 | 关节 |
|---:|---|---|
| 1 | `shoulder_pan` | 底座 |
| 2 | `shoulder_lift` | 肩部 |
| 3 | `elbow_flex` | 肘部 |
| 4 | `wrist_flex` | 腕部俯仰 |
| 5 | `wrist_roll` | 腕部旋转 |
| 6 | `gripper` | 夹爪 |

编号时一次只将一只舅机舵机连到总线，以免多只出厂 ID 相同的舵机同时响应。完成编号后再按 ID 串联和装配。

## 3. 实现原理

### 3.1 SCS215 协议层

`servo_bus.py` 实现了项目所需的 SCS 协议子集。本实物配置使用 `1,000,000 baud`，16 位寄存器值按高字节在前发送。位置控制使用的主要寄存器为：

| 地址 | 用途 |
|---:|---|
| `0x05` | 舵机 ID（EEPROM） |
| `0x09` / `0x0B` | 位置模式最小/最大限位 |
| `0x28` | 扭矩开关 |
| `0x2A` | 目标位置 |
| `0x30` | EEPROM 锁 |
| `0x38` | 当前位置 |

参考实现为课程给出的 [JyiDeng/lerobot_EAI_SCS215](https://github.com/JyiDeng/lerobot_EAI_SCS215)。本作业没有直接引入整个 LeRobot，而是在现有可移植串口实现上增加位置模式和同步写入。

### 3.2 归一化校准

对每个关节记录两个安全端点 `end_a` 和 `end_b`。用户输入归一化目标 `x ∈ [0,1]` 后，原始舵机目标为：

```text
raw = round(end_a + x * (end_b - end_a))
```

这个公式同时支持正向和反向区间；如果某个关节的 `end_a > end_b`，输入值增大时原始舵机位置会减小，不需要额外写一套反向公式。

SCS215 的位置反馈会在 `1023` 与 `0` 之间回绕，而位置模式下不能把这两个数简单视为相邻目标。因此，本次提交采用“不拆装、缩小可用范围”的方案：每个关节的两个校准端点都选在回绕点同一侧，归一化区间不跨越 `0/1023`。当前记录为：

| ID | 关节 | 0.0 端点 | 1.0 端点 | 0.5 目标 |
|---:|---|---:|---:|---:|
| 1 | 底座 | 694 | 1022 | 858 |
| 2 | 肩部 | 902 | 1022 | 962 |
| 3 | 肘部 | 11 | 315 | 163 |
| 4 | 腕部俯仰 | 661 | 1005 | 833 |
| 5 | 腕部旋转 | 388 | 914 | 651 |
| 6 | 夹爪 | 266 | 659 | 462 |

### 3.3 六关节同步运动

程序先读取六只舵机的当前位置，再用主机侧的 smoothstep 插值生成轨迹。默认在 2 秒内以 25 Hz 更新。每个更新周期只发送一个广播同步写包，数据包同时携带 ID 1～6 的目标位置，因此六个舵机在同一串口指令后更新目标。

上扭矩前会检查：

- 六只舵机是否都在位置模式；
- 六个输入是否都位于 `0～1`；
- 校准端点是否位于 SCS215 的 `0～1023` 位置范围；
- 当前姿态是否仍在校准安全区间内。

程序先将“当前位置”写为目标，再开启扭矩，防止舵机追赶上次留下的旧目标。完成、中断或异常退出时都会尝试释放六只舵机的扭矩。

## 4. 环境安装

Windows 下可双击 `setup_windows.bat`，或手动执行：

```bash
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
```

查看串口：

```bash
python homework_control.py ports
```

默认会自动识别 Waveshare/CH343 转接板。如果同时连接多个串口，可在子命令前指定：

```bash
python homework_control.py --port COM8 status
```

## 5. 舵机编号

将一只舵机单独连上总线。假设它当前是 ID 1，需要改为 ID 2：

```bash
python homework_control.py set-id 1 2
```

程序会依次关闭扭矩、解锁 EEPROM、写入新 ID、用新 ID 重新锁定，并读取一次位置来验证新 ID 通信。对六只舵机分别操作，直到 ID 1～6 齐全。

## 6. 位置模式和校准

如果舵机曾被切换到连续旋转模式，将六只舵机恢复为位置模式：

```bash
python homework_control.py position-mode
```

此操作会写 EEPROM，因此程序要求二次确认。不应重复无意义地执行。

校准某个关节，例如 ID 1：

```bash
python homework_control.py calibrate 1
```

也可以一次按顺序校准全部关节：

```bash
python homework_control.py calibrate 1 2 3 4 5 6
```

每个关节需手动摆到希望定义为 `0.0` 和 `1.0` 的两个安全端点。程序在每个端点连续读取 5 次位置并取中位数，最后原子更新 `config.json`。已提供的 `config.json` 包含本组之前测得的一组端点，机械臂重新装配或更换舵机后应重新校准。

只读检查通信、模式、位置和校准端点：

```bash
python homework_control.py status
```

## 7. 六关节控制

先使用干运行检查输入映射，该命令不打开串口：

```bash
python homework_control.py move 0.5 0.5 0.5 0.5 0.5 0.5 --dry-run
```

连接机械臂并确认周围安全后，第一次测试建议用 4 秒将六个关节移到各自校准区间的中点：

```bash
python homework_control.py --port COM5 move 0.50 0.50 0.50 0.50 0.50 0.50 --duration 4
```

六个数值依次对应 ID 1～6。程序会先打印归一化值与原始目标的对应表，然后要求输入 `MOVE` 确认。

## 8. 安全说明

- 首次运动时使用较长的 `--duration`，并随时准备切断舵机外接电源。
- 软件退出和释放扭矩不能代替物理断电。
- 不要把关节顶到机械死点作为校准端点，应保留一定余量。
- 机械臂重新装配、更换舵机或舵盘角度改变后，必须重新校准。
- 如果舵机出现异常声音、卡阻或线缆缠绕，立即断开舵机外接电源。
