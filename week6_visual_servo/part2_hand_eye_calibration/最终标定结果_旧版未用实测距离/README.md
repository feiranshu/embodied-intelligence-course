`hand_eye.json` 中的 `T_gripper_camera` 把 OpenCV 相机坐标转换到 URDF 的 `gripper_frame_link` 末端坐标。平移单位为毫米：

```text
 [-0.150022,  0.221698,  0.963506, -343.733152],
 [ 0.000000,  0.000000,  0.000000,    1.000000]]
```

- 相机光学原点到上述末端坐标原点的拟合距离：**376.13 mm**。它不是相机外壳到夹爪尖端的距离，也没有通过实物测量验证。
- 棋盘原点位置散布 RMS：**30.81 mm**。
- 棋盘方向散布 RMS：**5.98°**。
- 位置和方向散布表示同一批数据的一致性，不是对真实坐标的绝对误差。
