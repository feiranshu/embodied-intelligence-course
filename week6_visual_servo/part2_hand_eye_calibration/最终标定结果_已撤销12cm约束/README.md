# 最终手眼标定结果：采用约12 cm的实测距离依据

## 结果

最终选用**上一轮ID1基本固定的12组蓝圈样本**，在相机光学原点到URDF末端 `gripper_frame_link` 原点距离取 **120 mm** 的假设下，重新拟合手眼矩阵和经验关节角度换算。两轮分别计算，没有混合不同底座位置的数据；相机与末端安装关系未变，所以移动底座不影响手眼矩阵的适用安装。

| 比较项 | 重投影RMS | 相机到末端距离 |
| --- | ---: | ---: |
| 旧的无距离依据拟合 | 8.8364 px | 376.13 mm，与用户约12 cm的测量不符 |
| 上一轮，采用距离依据 | **9.1650 px，最终选用** | 120 mm，作为输入假设 |
| 最新一轮，采用相同距离依据 | 26.4433 px | 120 mm，作为输入假设 |

全部12张、每张48个角点均参与拟合，没有删除高误差照片。独立重新投影得到 **9.1650245 px**，与保存值一致。

- 棋盘位置散布RMS：**23.42 mm**。
- 棋盘方向散布RMS：**4.63°**。
- 这两个数衡量本批样本一致性，不是对真实位置、方向的绝对误差。

**120 mm来自你提供的近似距离，不是程序独立测出来的值。** 因为尚无测量不确定度，本次明确将长度固定为120 mm，只拟合平移方向等参数。若你量的是相机外壳到夹爪尖端，可能与光学原点到URDF原点存在差别；本结果按后者解释你的测量。

另外把假设距离改为100、140 mm进行敏感性计算，训练RMS分别约9.1631、9.1385 px，与120 mm时相近。这里的±20 mm仅用于敏感性分析，不是你报告的测量误差，也不是采集条件。这说明现有图像不能精确辨认安装距离，不能把输出长度接近120 mm当成独立验证。

## 配套FK换算

矩阵必须与JSON内的 `calibrated_joint_mapping` 配套：

```text
q_deg = angle_reference_deg
        + (unwrapped_raw - raw_reference_unwrapped) * signed_degrees_per_raw
```

读数展开使用 `inputs/advanced.json` 的规则；不可直接将0～1023原始读数减去表中参考值。课程 `common.py` 的 `calibrated_gripper_pose()` 已实现配套换算，复核程序给出了调用方式。ID6不参与五轴末端FK。

ID1、ID2在所选数据中几乎未运动，不能靠这批照片独立确定其方向与比例。表中这两轴的值是候选模型假设，其他比例也只是经验拟合，不能声称已经完成全行程物理角度标定。因此本结果作为当前最终交付的经验标定版本，**尚未独立验证真实定位精度**。

实际机械臂控制配置没有改动。第三、四部分仍使用原控制模型，尚未与经验映射统一，不能仅复制矩阵就认定其后续实机运动已经验证。
