# 当前最终手眼标定：无距离约束的经验解

## 选择结论

你已说明约12 cm的测量不可靠、末端坐标原点不清楚，因此**撤销120 mm距离约束**。当前最终结果选用上一轮ID1基本固定的12组蓝圈样本，在已测试的无距离约束候选中，采用全部角点训练重投影RMS最低的一组。没有直接复制网上其他机器的矩阵。

| 指标 | 当前最终结果 |
| --- | ---: |
| 全链角点重投影RMS | **8.8364 px** |
| 棋盘位置散布RMS | **30.81 mm** |
| 棋盘方向散布RMS | **5.98°** |
| 相机光学原点至URDF末端原点的拟合距离 | **376.13 mm，未实测验证** |
| 数据量 | 12张，每张48角点，全部参与 |

另一轮数据的无距离约束最低测试RMS为25.9751 px。两轮独立计算，没有混合底座位置不同的数据。相机与末端安装关系未变，因此移动底座本身不使手眼矩阵失效；各轮的基座到棋盘矩阵只适用于该轮位置。

本次选择以现有候选中最小图像残差为依据。刚性矩阵结构、完整样本重投影和相机前方深度已复核；经验比例没有落在原搜索边界。但**这些检查不能证明实际安装几何或绝对定位准确**。不同轮次的姿态分布不同，训练RMS排名也不是实机准确度排名。

特别是ID1、ID2在所选轮次几乎未动，其方向与比例未被这批数据独立识别；安装距离也没有可靠测量验证。当前结果应称为“最终经验标定版本”，不能称为已经验证的高精度结果。376.13 mm是解算输出，不是给机械臂规定的安装距离，也不是已确认的真实距离。

## 手眼矩阵

`T_gripper_camera` 将OpenCV相机坐标转换到URDF的 `gripper_frame_link` 末端坐标；平移单位mm。完整精度以JSON为准。

```text

 [ 0.590698,  0.801577, -0.092465,  150.041583],
 [-0.150022,  0.221698,  0.963506, -343.733152],
 [ 0,         0,         0,           1       ]]
```

## 必须配套的角度换算

不可只将矩阵与原来的FK直接组合。使用 `hand_eye.json` 中的 `calibrated_joint_mapping`：

```text
q_deg = angle_reference_deg
        + (unwrapped_raw - raw_reference_unwrapped) * signed_degrees_per_raw
```

| --- | ---: | ---: | ---: |
| 1 | 1331.5 | 90.762463 | -0.351906158 |
| 2 | 901 | 40.672965 | +0.351906158 |
| 3 | 159 | 15.123188 | +0.353853168 |
| 4 | 656 | -117.993246 | +0.357854376 |

先按 `inputs/advanced.json` 的规则展开原始读数，再使用上式。配套实现见课程 `common.py` 中的 `calibrated_gripper_pose()`，复核程序展示了调用。ID6不参与五轴末端FK。上述参数是经验拟合，不是已通过实物角度测量确认的全行程舵机标定。

实际机械臂控制的 `advanced.json` 未改动。第三部分现已在进程内配套本经验映射的FK／IK，第四部分仍使用原模型；这不代表其后续实机视觉运动已经验证。任务三操作见 `part3_visual_servo/README.md`。
