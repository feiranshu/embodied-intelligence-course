# 手眼标定最终结果

本目录保存 2026-11-23 确认的最终实验结果。棋盘为 8 × 6 个内角点，方格边长 25 mm。

| 指标 | 结果 |
| --- | ---: |
| 12 组拟合重投影 RMS | 3.42 px |
| 8 组留出重投影 RMS | 36.39 px |
| 留出棋盘原点相对拟合结果的差异 RMS | 114.38 mm |
| 拟合相机光学原点到末端原点的距离 | 207.47 mm |

`hand_eye.json` 保存 `T_gripper_camera`、关节偏差、底座角度展开参考和逐图误差。20 张原图、样本清单、相机内参、关节配置及 URDF 与结果一起保存。

底座原始读数跨过旧软件映射的分界时，求解使用本批拟合数据的角度展开参考。4 号腕轴使用重拍实验的运动学方向。保留的实机控制配置仍待独立验证，留出误差衡量样本间的一致性。

在上一级 `part2_hand_eye_calibration` 目录执行：

```powershell
python verify_final_calibration.py
python web_app.py
```
