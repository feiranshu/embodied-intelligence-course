# 蓝圈版12张手眼标定的误差诊断

## 结论

**当前主要故障在“机器人关节读数→与照片对应的真实末端位姿”这一输入链路，最明显的是ID1。继续反复拍同样的12张、修改矩阵安装距离或拟合常量零角，不能解决已经存在的运动矛盾。**

用户已经明确确认：相机刚性固定在末端，期间没有调整；机械臂底座、棋盘和白板也始终未移动。

现有记录足以定位到这条输入链路，但不足以在“反馈值/角度换算不准确”和“照片与反馈时间错配”之间唯一归因。没有证据可以直接断言某只舵机损坏。程序没有记录两侧时间戳，所以不能从历史数据补出这个缺失证据。

本次对应结果：2026-10-16 17:23:36生成，12组，联合重投影RMS 45.9384px。源数据的逐图机器人/相机位姿及66对旋转比较位于observations.json。

## 1. ID1存在不依赖手眼矩阵的运动矛盾

| | 第5张 | 第6张 |
|---|---:|---:|
| ID1 | 632 | 997 |
| ID2 | 903 | 902 |
| ID3 | 188 | 188 |
| ID4 | 662 | 662 |
| ID5 | 841 | 841 |

现有角度比例为300/1023度/格：

- 底座365格变化对应107.038°。
- 仅肩部另变化1格，约0.293°；其他三个角度不变。
- 整体旋转角应位于约106.745°～107.331°，与具体常量零角无关。
- 当前FK算出107.038°，图像PnP却只有7.505°。

固定相机到末端的旋转变换只改变旋转轴的坐标表达，不改变相对旋转角；安装平移也不能改变这个角度。因此无法通过选一个更好的固定手眼矩阵消除约100°的差异。

这不是“某个位姿距真实位置差几毫米”的问题，而是两套输入描述了不同的运动。按现有角度模型，第5和第6张不能同时满足固定手眼关系。

632、997都通过了用户指定的区间筛选。区间筛选只排除了0～30和1000～1022，不能证明其他数值自动就是精确角度，也不能证明图像与读数同步。

## 2. 相邻俯仰关节组合也有不一致

- 第7→8张：ID3变化-71格、ID4变化+50格。当前方向配置让两个俯仰转角同向相加，FK转角35.484°，相机转角8.275°。
- 第3→4张：仅ID3变化-14格，FK转角4.106°，相机转角7.156°。
- 第11→12张：仅ID3变化+9格，FK转角2.639°，相机转角4.011°。

这些说明ID3/ID4的方向、比例和时间对应也需要核实。不能从这些少量数据直接计算出可靠的新比例，更不能只为降低误差就自动改方向或零角。纯单轴运动的角度大小不取决于该关节的参考零角，改零角不能修复变化量不符。

## 3. 已经排查了什么

### 蓝圈定向

12条记录均保存blue_circle来源和ordered_corners。逐张联系图中，紫色0均在蓝圈旁同一物理内角点，未发现这批仍有起点翻转。求解使用保存顺序，不重新改变编号。

### 单图拟合

这批单图PnP重投影RMS约0.119～0.147px。照片里的棋盘本身能够很好拟合，不支持把45.94px主要归因为普通角点定位噪声。

### 内参敏感性

用本批12张重新做相机内参拟合，得到fx约904.34、fy约908.00px，原值约965.39、969.16px。新拟合的部分畸变系数很大，且本批视角范围有限，因此不替换任务一内参，也不能把本批自拟合低误差当成独立验证。

另将原内参的焦距分别乘0.5、1、2，只检查第5→6张的相机相对转角，分别约3.08°、7.51°、7.33°。这不是完整内参不确定度分析，但说明普通焦距偏差并不能轻易把该对运动解释成107°。

### 手眼求解坐标关系

使用本批相同12组FK姿态，设定已知相机变换：旋转向量[0.2,-0.1,0.15]，平移[40,-20,60]mm。生成完全一致的合成相机位姿，再调用同一个闭式手眼求解入口，矩阵最大元素误差约2.15e-11，平移误差约2.70e-11mm。

这验证了该测试下求解入口的坐标方向和基本数学关系；不能据此证明全部真实FK参数正确，也不能保证任意真实数据的非线性优化找到全局最优。不过，上面的旋转角矛盾已独立于优化器存在，换优化算法也不能让它严格相符。

## 4. 当前最明确的责任边界

1. 不应继续要求操作者用更稳的手或更多相似照片解决它。
2. 原程序把未充分验证的角度换算直接作为标定输入；这一前提需要纠正。
3. 当前图像缓存与六轴串口读取没有共同时间记录。它是确实存在的采集可追溯性缺口，但还不能断言本批一定因延迟而错配。
4. 若第5→6张是在完全静止、画面和读数均充分更新后记录，时间错配的可能性会降低，ID1反馈与真实角度的映射就成为首要问题。

## 5. 最小的后续定位动作

不再重新收集12张。真正需要的是一段有独立几何参照的单轴观察：仅ID1变化时，同时记录真实轴角、原始反馈和新鲜图像的时间，区分“轴实际约7.5°但反馈按现有比例声称107°”与“轴确实转了107°但保存了错误时刻的图像”。

现有12组数据没有这些独立角度和时间信息，不能靠离线计算唯一恢复。需要补的是这一个诊断证据，而不是重复整套标定。此次未实际驱动舵机、未修改控制范围或标定参数。

## 6. 结果使用

当前45.94px结果及889.67mm拟合距离均不能作为实际安装测量。当前拟合出的ID2～4巨大偏置不能直接写入配置。
