# 任务三：简单版视觉伺服网页

## 最新默认行为：持续调整到中央区域

按你确认的目标，**标记中心基本进入画面中央区域就完成**，不要求标记放大或覆盖整幅图像。默认勾选“只居中，不向前靠近”；中央区域宽高比例20%，即横纵方向40%～60%的黄色框。可修改“中央区域宽高比例”，数值更大表示更宽松。

点击“持续调整直到居中”后，会持续识别并执行下一步，直至居中、你停止，或遇到通信／控制器错误。步数和总行程默认均为0，表示不限；需要时可设置正数。

识别已加入更宽的自适应阈值范围、亚像素角点处理，普通识别失败后尝试增强对比度及2倍放大识别。只采用成功解码的指定ArUco ID，不会把普通黑块当作标记。标记ID已识别但距离解算失败时，仍可执行只居中任务。

短暂漏检时，暂停发出新的运动请求，保持本次任务等待；重新识别到目标后自动继续。已在执行中的单步仍由运动控制器处理。摄像头读取失败、画面停止更新、网页连接中断或手动停止仍会请求停止，不会使用旧画面盲走。

**更新后先在原任务三服务窗口按Ctrl+C退出，再双击根目录的启动CMD，刷新网页。** 原服务仍运行时，CMD只会打开旧页面，无法加载新代码。

## 1. 双击启动

在最外层项目根目录，双击 **`启动任务三视觉伺服.cmd`**。

浏览器会打开 **http://127.0.0.1:8766/**，使用已安装的Conda `py312` 环境和 **GENERAL WEBCAM**。页面打开后只预览，点击“执行一步”或“开始自动调整”才会连接机械臂并请求运动。

**先在任务二原服务窗口按Ctrl+C结束它。** 只关网页标签不会释放摄像头、串口；两个任务同时运行会争用同一设备。任务三摄像头打开失败时仍可显示网页，原因会直接显示在画面下方，释放占用后点击“重新连接摄像头”。

启动窗口保持打开。结束整个服务时，在该窗口按Ctrl+C。若CMD发现任务三服务已经运行，只会打开原页面；代码更新后要先退出原服务，再启动。

## 2. 准备标记

1. 在网页点“打印默认ID 0标记”。
2. 按**实际大小／100%**打印，关闭“适合页面”。默认字典 `DICT_4X4_50`、ID为0。
3. 用尺测量**黑色正方形外边长**，不要包含白边。设计边长40 mm，如果打印后不是40 mm，在网页里填真实边长。
4. 把标记固定在机械臂前方，让摄像头完整看到黑色边框和外围白边。

文件夹里也有 `print_marker.html`、`marker_id0_40mm.svg`、`marker_id0_40mm.png`。HTML打印尺寸由SVG确定；PNG自身像素大小不保证打印后的毫米尺寸。

## 3. 网页操作

### 第一次先预览

- 识别成功后，画面出现绿色框、红色中心点，上方显示ID和估计深度。
- 黄色框是图像中央40%～60%的区域。
- 修改参数后点“应用参数”，等待新的识别画面。默认只跟踪ID0；有其他ID标记时不会替代指定目标。

### 单步观察

1. 操作者在机械臂旁，确认周围无障碍并能切断外接电源。
2. 默认步长10 mm，也就是每次请求1 cm。“只居中，不向前靠近”现在默认已勾选。
3. 点击“执行一步”，观察机械臂和新的画面。单步完成只表示本次动作执行结束，不表示整个视觉任务已完成。
4. 核对实际画面是否按预期改善后，再使用自动调整。

### 自动调整

点“持续调整直到居中”，每次从当前画面重新决定一个方向。默认中央区域20%时：

| 标记中心位置 | 请求的相机坐标方向 |
| --- | --- |
| 左侧40%以外 | 向左 |
| 右侧60%以外 | 向右 |
| 上侧40%以外 | 向上 |
| 下侧60%以外 | 向下 |
| 已进入中央区域，且比停止距离至少远一个步长 | 向前 |
| 已居中，达到停止距离或剩余不足一个步长 | 结束 |

左右和上下同时偏离时，优先纠正归一化偏差更大的方向。默认只居中，不执行向前接近。只有取消该勾选后，才使用停止距离200 mm；它是标记相对相机光学坐标的Z深度，不是夹爪与标记的净间隙。

每次以当前相机朝向将方向转换到基座，调用机械臂末端直线运动接口，再观察新画面。**1 cm是模型中的末端位移请求，不是外部尺子验证过的真实相机位移**；末端转动、标定误差、机构误差都可能造成差别。当前手眼训练RMS约8.84 px，实机方向、准确度及最终任务效果尚未验收。

## 4. 停止与故障提示

- 点红色“停止”，或网页获得焦点时按Esc。
- 离开页面会请求停止；网页轮询中断超过3秒时，服务也会请求停止。停止不是瞬时机械急停，仍应能切断外接电源。
- 目标短暂丢失时等待重新识别，不发新运动；摄像头异常、通信或运动失败会结束本次运行。
- 步数和总行程默认0，表示不限；自行设置正数后，到达对应设置时结束，日志不会冒充任务到位。
- 原机械臂控制器的关节范围、跨零处理和反馈检查继续使用。本次没有扩展已有运动范围，也不会自动将机械臂摆到其他预设姿态。
- 如果显示“当前姿态不在范围内”或“IK无解”，页面会保留具体原因。需要将机械臂调整到原控制程序允许的可达姿态；检测到标记不代表任意姿态都能完成所需方向的笛卡尔运动。
- 停止及退出会请求关闭驱动，机械臂可能失去支撑，请注意承托。若停止反馈失败，页面和日志会明确显示失败，不能视为已经停止。

## 5. 当前标定的接入

默认读取任务二 `最终标定结果/hand_eye.json`，不是网上其他设备的矩阵。

本次修复了原任务三“新手眼矩阵配旧FK”的不一致：运行时同时应用JSON中的经验角度映射，用同一模型做FK、方向换算及IK。改动只存在于任务三进程内，**不改写week4的advanced.json**。

原URDF角度边界转换到新的角度参考下，保持原本允许的物理读数集合不变，而不是直接把新角度与旧零点下的边界比较。任务二数据中的ID1、ID2方向仍未独立识别，任务三的运动准确度需要现场确认；软件模型配套不等于该经验模型已被实物验证。

## 6. PowerShell启动方式

在 `week6_visual_servo` 文件夹打开PowerShell：

```powershell
conda activate py312
python .\part3_visual_servo\web_app.py
```

也可直接用已有环境：

```powershell
& 'D:\software\anaconda\envs\py312\python.exe' .\part3_visual_servo\web_app.py
```

按需指定串口或摄像头索引（COM8只是示例）：

```powershell
python .\part3_visual_servo\web_app.py --port COM8 --camera 0
```

默认按GENERAL WEBCAM设备名选择，不依赖相机始终是索引0。串口默认自动识别。
