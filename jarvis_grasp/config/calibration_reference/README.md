1. 2026-11-22 晚舵机已重新居中装配（ID 1–4 原始读数区间均为非跨零区间：`ID1 141..868`, `ID2 78..711`, `ID3 279..860`, `ID4 104..758`, `ID6 260..662`），`vendor/scs215/advanced.json` 已同步更新为实测非跨零映射与经过 20 组实拍图像核验的正方向 `directions=[1,1,1,1,1]`。
