# 2026-10-16：逐关节角度换算修正

## 已修正的代码问题

原Kinematics使用统一角度比例，不能直接与任务二保存的逐关节方向、比例和参考角配套。现新增 `radians_per_count` 和 `with_joint_calibration(mapping)`，FK、IK角度边界、角度到反馈读数的反算统一使用逐关节比例。方向仍保持±1，不再把非单位比例塞进方向字段。

换算为：`角度 = 参考角 + (展开读数 - 参考读数) × 带方向比例`。

导入校正时，URDF角度边界随参考角一起转换，以保持原本允许的物理读数集合不变；原关节范围、跨零控制、到位反馈和停止逻辑继续保留。原advanced.json没有被自动改写。

week6任务三现调用同一个week4接口，不再保存另一份角度换算实现。

## 使用方式

在本目录PowerShell中，原有命令可额外指定任务二结果。例如仅模拟：

```powershell
conda activate py312
python .\advanced.py --joint-calibration '..\..\week6_visual_servo\part2_hand_eye_calibration\最终标定结果\hand_eye.json' --simulate text '向前移动10毫米'
```

参数放在 `text`、`keyboard` 等子命令之前。实机仍需要原有 `--execute`，应先现场核对方向和当前姿态；此修正并不等于新参数的实机运动已验收。
