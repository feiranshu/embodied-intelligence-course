# 文件清单

项目根目录是本文件与 `README.md` 所在目录。现有目录结构按用途保留，避免改动源码、文档和演示资料之间的相对路径。

| 位置 | 内容与用途 |
|---|---|
| 根目录 `README.md`、`HANDOFF.md`、`本地复现.md`、`文件清单.md` | 总入口、历史交接、当前电脑的复现步骤和文件索引 |
| 根目录 `课堂练习报告.md`、`classroom_servo.py`、`serial_port.py` | 双舵机课堂实验及自动串口选择 |
| 根目录 `read_servo.py`、`write_servo.py`、`set_id.py` | 课堂协议的简短样例；后两者会写入舵机，日常控制使用完整工程入口 |
| 根目录 `Hackathon任务报告.md`、`林邵坪24307090026.md` | 课程任务报告与 LeRobot 功能梳理 |
| `演示视频/` | 立正、动作2、动作3、语音控制四段既有录像 |
| `so101_scs215_portable/` | 当前进阶工程，姿态、动作、IK、语音、视觉和网页控制 |
| `so101_scs215_position_homework/` | 独立的六轴归一化位置控制作业 |
| `week6_visual_servo/` | 第六周相机内参、手眼标定、ArUco 视觉伺服和任意物体跟踪；先读该目录的 `README.md` |

## 进阶工程内部

| 文件或目录 | 用途 |
|---|---|
| `README.md`、`进阶使用说明.md`、`HANDOFF.md`、`AGENTS.md` | 安装操作、技术交接与维护规则 |
| `config.json`、`advanced.json` | 串口/关节配置与姿态、运动学、语音、视觉配置；现场标定值不能跨设备直接认定有效 |
| `servo_bus.py`、`diagnose.py`、`diagnose_windows.bat` | SCS215 协议与只读硬件诊断 |
| `advanced.py`、`calibration.py`、`joint_mapping.py` | 姿态、动作、关节映射与末端 IK |
| `controller.py`、`web/index.html` | 本机或局域网网页控制与末端六方向页面 |
| `voice_control.py`、`models/vosk-model-small-cn-0.22/` | 中文语音控制及随包提供的离线识别模型 |
| `vision_control.py`、`web/black_ball.html` | 黑球检测及尚未完成实机验收的视觉跟随入口 |
| `so101_new_calib.urdf` | IK 使用的关节和工具端几何；外观 STL 网格未随包提供 |
| `requirements.txt`、`requirements_advanced.txt`、`setup*_windows.bat`、`select_python.bat`、`start_*.bat` | 依赖清单、安装、已激活 Conda 环境选择和启动入口 |
| `test_offline.py`、`test_advanced.py` | 无硬件测试；部分测试需要 Vosk 模型与完整进阶依赖 |
| `verification/` | 历史实机 JSON 反馈、检查摘要、视觉图和四段合成语音 WAV；不是当前现场状态 |

## 独立位置作业内部

`homework_control.py` 是命令行入口，`servo_bus.py` 为该作业自己的协议实现，`config.json` 保存不跨反馈零点的六轴线性校准。`test_offline.py` 为离线测试；`README.md`、`作业说明.md`、`HANDOFF.md`、`AGENTS.md` 说明操作、验收和约束；`requirements.txt`、`setup_windows.bat` 用于安装。两个工程中同名的配置和协议文件用途不同，不应互换。

`.gitignore` 分别排除 `.venv/`、`__pycache__/` 等机器生成文件。复制或打包时保留源码、配置、URDF、Vosk 模型、验证资料和视频；虚拟环境按 [本地复现说明](本地复现.md) 在目标电脑重新创建。
