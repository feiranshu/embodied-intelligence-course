# 本地复现说明（Windows）

## 目录与环境

本说明中的“项目根目录”是包含 `README.md`、`classroom_servo.py`、`so101_scs215_portable/` 和 `so101_scs215_position_homework/` 的目录。压缩包解压后可能多一层同名文件夹；运行命令前先进入实际的项目根目录。整个项目可以放在任意用户目录，源码不依赖旧电脑的用户名、盘符或 COM 编号。

建议安装标准 Windows CPython 3.11 或 3.12，并确保 `python --version` 指向该解释器。进阶依赖用这两个版本验证更方便；不要把应用内置或 MSYS 的 Python 当作可移植的系统安装。每个工程使用自己的 `.venv`，不要互相复制虚拟环境或混用两个 `config.json`、`servo_bus.py`。

### 已有 Conda 环境

如果已通过 Conda 管理 Python 3.12，可以直接使用已有环境，无需创建项目 `.venv`。在 Anaconda Prompt 或已初始化 Conda 的 PowerShell 中运行 `conda activate py312`，然后分别进入下面的工程目录执行 `python -m pip install -r requirements_advanced.txt`（进阶工程）或 `python -m pip install -r requirements.txt`（位置作业）。后续命令中的 `.\.venv\Scripts\python.exe` 换成 `python` 即可。进阶工程的启动批处理会优先使用已激活的 Conda 环境，再选择项目 `.venv`。当前电脑的 `py312` 环境已安装进阶依赖，2026-10-12 使用该环境完成进阶工程 220 项及位置作业 8 项离线测试。

## 进阶工程：姿态、IK、语音与视觉

在 PowerShell 中进入 `so101_scs215_portable` 目录，运行：

```powershell
.\setup_advanced_windows.bat
.\.venv\Scripts\python.exe -X utf8 advanced.py --simulate text "立正"
.\.venv\Scripts\python.exe -X utf8 -m unittest test_offline.py test_advanced.py
```

如果系统默认 Python 不合适，可把标准 Python 的完整路径传给安装脚本，例如 `.\setup_advanced_windows.bat "C:\path\to\python.exe"`。基础网页控制只需要 `.\setup_windows.bat`；`start_cartesian.bat`、`start_voice.bat`、`start_vision.bat` 和 `start_advanced_demo.bat` 需要进阶依赖。

`advanced.json` 中的 URDF 文件名相对于本工程目录解析；随包提供 `so101_new_calib.urdf`。Vosk 中文模型也随包放在 `models/vosk-model-small-cn-0.22/`，标准口令离线转录无需密钥。模型体积较大，复制时不要漏掉 `am/final.mdl`。URDF 中的 `assets/*.stl` 外观网格没有随包提供；当前运动学只读取关节、连杆和工具端几何，不加载这些网格。若要用独立 3D 软件显示完整模型，需另外取得与该 URDF 匹配的网格文件。

实机连接后先运行只读的 `.\.venv\Scripts\python.exe -X utf8 diagnose.py`。串口配置默认为 `auto`，自动寻找 CH343；多块相同转接板时通过 `--port COMx` 或本工程 `config.json` 指定。实机运动入口和验证边界见 [总交接说明](HANDOFF.md)及[进阶使用说明](so101_scs215_portable/进阶使用说明.md)。

## 独立六轴位置作业

进入 `so101_scs215_position_homework` 目录，运行：

```powershell
.\setup_windows.bat
.\.venv\Scripts\python.exe -X utf8 -m unittest test_offline.py
.\.venv\Scripts\python.exe -X utf8 homework_control.py move 0.5 0.5 0.5 0.5 0.5 0.5 --dry-run
```

干运行只计算六个目标值，不打开串口；现有配置应得到 `858, 962, 163, 833, 651, 462`。本工程的标定区间与进阶工程不同，不能复制配置互换。

## 课堂样例与资料

根目录的 `classroom_servo.py`、`read_servo.py`、`write_servo.py`、`set_id.py` 使用 `pyserial`；从项目根目录运行。课堂脚本默认自动寻找唯一的 CH343 转接板，也可显式指定 `--port COMx`。`read_servo.py` 为只读示例；`write_servo.py` 会驱动 ID 1；`set_id.py` 会写 EEPROM。后两者只在现场条件满足时使用。

`演示视频/`、报告及 `so101_scs215_portable/verification/` 是既有证据，不参与程序安装。离线测试、模拟运动、历史视频都不能代替当前电脑上的串口、麦克风、摄像头和真实运动验收。视觉闭环尚未完成实机验收；1.2 的六方向和外部定距测量证据仍不完整。
