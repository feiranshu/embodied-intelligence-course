## 1. 任务目标

本项目围绕 SO-101 六自由度机械臂实现三部分功能：

1. 4.1：摄像头拍摄人体手臂动作，视觉模型解析动作并控制机械臂模仿；
2. 4.2：把前几周完成的状态读取、预设姿态、连贯动作、IK、视觉检测与追踪等能力封装成 LLM Agent Tools；

所有实机运动仍由本地安全层执行和约束。大模型只选择工具及参数，不直接向舵机写入未经校验的位置。

## 4. 4.2：把已有功能封装为 Agent Functions

### 4.1 实现原理

传统命令由人明确指定要运行哪个 Python 函数；4.2 改为由外部 LLM 理解自然语言，再自主选择已经登记的工具。例如用户说“做一次左右摆动”，模型不是直接生成电机数值，而是调用：

```json
{"name": "run_action", "arguments": {"name": "左右摆动"}}
```

Agent 程序随后检查工具名、参数、运动权限和路径，执行本地函数，把执行结果返回模型，最后由模型向用户说明结果。核心流程为：

```text
用户自然语言 → LLM 选择工具 → 本地安全检查与执行
→ 工具结果返回 LLM → LLM 继续决策或回答
```

这意味着 4.2 完成的不是一个新机械动作，而是把原先分散的程序变成一组大模型能够理解和调用的标准接口。
